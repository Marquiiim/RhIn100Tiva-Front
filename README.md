# Teste RHIN100TIVA - Frontend

## Sobre o Projeto

Aplicação web para gerenciamento de tarefas, desenvolvida com foco em usabilidade, organização e performance. A interface permite criação, visualização, atualização e remoção de tarefas, contando com paginação eficiente e layout responsivo para diferentes tamanhos de tela.

---

## Tecnologias Utilizadas

* React
* Shadcn/UI
* Tailwind CSS
* Axios

---

## Requisitos

* Node.js 14 ou superior
* NPM ou Yarn

---

## Instalação

```bash
npm install
```

---

## Execução

### Ambiente de desenvolvimento

```bash
npm run dev
```

### Build de produção

```bash
npm run build
npm run preview
```

---

## Componentes

### PaginationTask

Componente responsável pela paginação de dados, com validação automática de limites e controle de navegação, incluindo desabilitação de ações inválidas.
